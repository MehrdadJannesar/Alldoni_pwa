# IRANSans Font Files

IRANSans web font files in this folder:

```text
IRANSansWeb(FaNum).woff
IRANSansWeb(FaNum)_Bold.woff
IRANSansWeb(FaNum)_Light.woff
IRANSansWeb(FaNum)_Medium.woff
IRANSansWeb(FaNum)_UltraLight.woff
```

The app stylesheet already references these files and will use IRANSans automatically when they are present.
